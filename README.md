## CN2、CN2 GIA、KVM……这几个词到底是什么意思

很多新手买搬瓦工之前最头疼的就是这堆缩写。我当初买错过一次，花了冤枉钱，所以这里单独说清楚：

**CN2 GT**：电信 CN2 骨干网的普通版，三网（电信/联通/移动）走法不同，晚高峰会有一定波动。价格相对最低，入门可用。

**CN2 GIA**：CN2 骨干网的高端版，全程双向走 CN2 GIA，延迟表现明显更稳定，在测试中搬瓦工 CN2 GIA 机房的延迟可以比某些服务商低几十到一百毫秒以上。DC6（洛杉矶）和 DC9（洛杉矶）是最受欢迎的两个节点。

**KVM**：指虚拟化架构，搬瓦工目前全线套餐都是 KVM 架构，支持安装各类 Linux 发行版，不用纠结这个词。

**香港 CN2 GIA**：延迟最低，可达 1Gbps 带宽，价格较高，适合预算充足、对延迟极度敏感的用户。

一个很容易踩的坑：不少新用户购买搬瓦工后发现没有 CN2 GIA，很大原因是选错了机房。CN2 GIA 线路在「E-Commerce」系列套餐里，买之前一定要确认机房类型。
